### 下载与启动

普通用户下载 **GWYF-Vision-0.3.0-Windows-免装Python.zip**，完整解压后双击 **启动识牌助手.cmd**。无需安装 Python 或运行 pip；内含运行依赖、本地模型及微软 WebView2 离线安装器。约 278 MiB，主要体积来自运行环境和离线安装器。源码开发包为 GWYF-Vision-0.3.0.zip，不包含 Windows 运行环境。

选择游戏窗口，按 **Ctrl+Shift+Space** 截一帧。默认整帧自动找牌，不必先框牌区。完整、可靠且通过牌组/历史校验时直接计算建议；有疑点时保留可编辑草稿。Ctrl+Shift+Enter 可采用已核对牌面。截图不上传，归档仍需手动点击。

### 改进

- 整张牌正面/背面/背景模型过滤桌面文字、漂浮总点数与非牌物体。
- 大点数/花色网络与独立模型复核，结合多裁块、大小花色和红黑颜色一致性。四个模型共 1,847,539 参数，约 7.05 MiB。
- 多尺度完整牌面定位、四朝向校正；手动牌区只筛选中心，不再裁断牌角。默认不沿用旧错误裁切。
- 二十一点区分玩家/庄家明牌与不可读牌背；扑克区分当前五张和后方弃牌。
- 可靠识别自动计算，重复截图不重复计牌；不完整、重复牌和低分停止自动采用与旧建议。
- 420×341 紧凑布局保留牌面、结果和操作同屏。新增启动日志与免装 Python 启动器。
