### 下载

下载 **GWYF-Vision-0.3.2-Windows-Portable.zip**，关闭旧浮窗，完整解压，双击 **启动识牌助手.cmd**。内置 Python、CPU 模型与依赖；缺少 WebView2 时使用包内微软离线安装器，无需安装 Python 或执行 pip。

### 新增扑克换牌快捷键

| 操作 | 默认按键 |
|---|---|
| 按推荐换牌（助手内确认） | F7 |
| 识牌并计算 | F8 |
| 归档本手 | F9 |
| 采用已核对草稿 | F10 |
| 游戏洗牌后重置手牌与已用牌 | F11 |

页头“快捷键”可修改、停用和保存五项按键。保留原有自定义设置；如果旧配置已经占用 F7，新换牌键暂不启用，在设置里另选即可。

F7 采用当前推荐保留方案，弃牌立即进入已用牌，接着等待补牌。**仍需在游戏内手动换牌**，换好后按识牌键读取完整五张。重复按键不会再次换牌；可撤销。推荐全留、计算中、未采用草稿和旧建议不会改变手牌。

同时修复草稿未采用时旧建议继续显示，以及识牌过程中修改手牌/历史可能被异步结果覆盖的问题。换牌建议与按钮保持紧凑同屏。
