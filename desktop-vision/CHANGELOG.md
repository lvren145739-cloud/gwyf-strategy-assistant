# 0.3.0 — 2026-10-20

- 扩大本地识别模型至 1,847,539 参数、四个 ONNX 文件约 7.05 MiB：整张牌验证 + 大点数/花色网络 + 独立模型复核。
- 新增背景负例训练、牌面/牌背/背景分类，过滤漂浮数字、桌面文字和非牌物体；结合红黑颜色与大小花色一致性检查。
- 默认整帧定位，多尺度轮廓和四朝向校正；手动牌区只筛选完整牌面的中心，旧选区不会强制裁断牌角。
- 自动区分二十一点庄家明牌/背面与玩家手牌；扑克识别当前五张所在行，排除后方弃牌。
- 完整可靠牌面自动采用并计算；重复识别不重复计牌，疑点草稿不覆盖原手牌并停用旧建议。
- 改进核对界面的状态文字、候选框和紧凑布局，不再把未读全的候选显示成“100%识别成功”。
- 提供 Windows x64 免装 Python 包：内置官方嵌入式 Python、固定版本依赖、离线 WebView2 安装器和启动日志。
- 增加真实 Windows WebView2/EnumWindows/MSS 自建窗口验证、自动计算回归和多版本推理验证；保留失败与未覆盖范围。
- 修正一处开发评测标注 A♥ 为 A♦；未使用该保留评测帧重新训练，详见 tests/annotation-correction.json。
- 保持 MIT、英文署名和稳定网页策略引擎。

- 增加真实pywebview 6.2.1扫描、生成JS、Python RPC与网页集成回归，覆盖两种就绪时序、缺失接口、错误恢复及全部公开方法。原生窗口列表在测试中使用固定样本，未声称Windows游戏实机已通过。
- 模型、依赖、策略规则、存档位置及MIT许可保持一致；已有0.2环境可覆盖更新，不需要重装Python或重新下载模型依赖。

# 0.1.0 — 2026-10-20

首个独立的截图识牌实验版，基于网页 v7.7.2。

- 增加 Windows 全局快捷键：Ctrl+Shift+Space 截一帧，Ctrl+Shift+Enter 采用已核对牌面。
- 增加 WebView2 置顶浮窗、小窗布局、一次性牌区框选和本机存档。
- 自训练点数/花色小型 CNN，导出 ONNX，合计约369.4 KiB；CPU单线程，无云端模型、GPU或持续截图要求。
- 提供识别草稿、原始牌面预览、直接改牌、补录、放弃草稿与低分/边界提示。
- 二十一点考虑已用牌，归档已录入玩家牌、庄家明牌和后续补牌。
- 扑克确认换牌即记录弃牌；重复截图不重复计牌；补牌按保留牌身份校验，允许识别顺序变化。
- 增加可撤销的归档与重置、生效道具数量、工作线程策略计算，防止迟到的旧结果覆盖新截图。
- 单文件界面预览支持手动录牌计算；桌面版额外支持测试图片。
- 完成两份视频的开发检查，保留遮挡和极端角度失败样例；没有把开发结果表述为正式识别准确率。
- 补充模型散列、来源说明、实测性能和运行环境体积。

状态：实验版。Windows原生窗口、快捷键、WebView2及游戏内焦点尚未实机验证。未替换线上稳定网页，未改变原有v7.7.2规则模型。
