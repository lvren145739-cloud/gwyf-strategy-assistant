# GWYF Vision 0.3.2 — 本地截图识牌决策助手

Created by lvren with GPT-6.1Sol.

适用于《朋友，梭哈吧》的二十一点和单人扑克截图识牌。按快捷键截一帧，自动寻找可见牌面；识别完整且通过一致性、牌组和历史记录检查后，直接计算建议。看不清的牌保留为可编辑草稿，不覆盖原手牌，也不继续显示过时建议。不会读取游戏内存或预知底牌。

## Windows 免装 Python 版

1. 完整解压 `GWYF-Vision-0.3.2-Windows-Portable.zip`，不要在压缩包内部运行。
2. 双击 `启动识牌助手.cmd`；也可用 `.vbs` 静默启动。
3. 选择游戏窗口，按 **F8** 截一帧。默认整帧找牌，不必先框牌区。
4. 有疑点时直接改草稿中的牌、归属或删除多余候选，再采用并计算。**F10** 可采用已核对草稿。

适用于 Windows 10/11 x64。包内有标准 Python 3.14、依赖、CPU 模型和微软 WebView2 离线安装器；不用安装系统 Python、不运行 pip、不依赖云端识别或 GPU。缺少 WebView2 时首次启动会使用包内安装器准备，可能需要稍等。体积主要来自完整运行环境和微软离线安装器，模型本身约 **10.50 MiB**。第三方组件各有许可，见 NOTICE.md。

默认自动确定牌区；手动框区用于限定归属，中心点筛选不会直接裁掉完整牌角。浮窗支持紧凑显示，可靠识别后返回结果区域。换位置或改变视角后可重新校准或切回自动找牌。最小化游戏请先恢复窗口；独占全屏无法截图时可用无边框窗口模式。

截图只在本机内存处理，不自动上传或保存。存档与启动日志位于 `%LOCALAPPDATA%\GWYF-Vision-Prototype`。重复截图不增加已用牌；归档需要主动点击或按快捷键。扑克确认换牌即记录弃牌，重新截图不会把桌面后方弃牌计为当前五张牌。

## 快捷键

| 操作 | 默认按键 |
|---|---|
| 在助手内确认推荐换牌 | F7 |
| 识牌并计算 | F8 |
| 归档本手 | F9 |
| 采用已核对草稿 | F10 |
| 游戏洗牌后重置当前手牌与已用牌 | F11 |

点击页头 **快捷键**，点击对应按键后按下新组合，再点 **保存并生效**。五项都可以修改或单独停用；Esc 取消录入。设置独立存于 `hotkeys.json`，下次打开自动恢复，手牌撤销不会覆盖按键设置。重复绑定或被其他程序占用时会提示，原来可用的按键不会因保存失败而丢失。

录入按键时暂时释放全局快捷键；切离所选游戏和助手时也会释放，避免占用其他程序的 F 键。归档不会处理未核对草稿，识牌过程中不会归档或重置；重置可撤销，重复触发空牌堆重置不会覆盖撤销记录。

换牌快捷键只确认助手当前推荐方案、记录弃牌并等待补牌，不向游戏发送换牌指令。草稿未采用、计算未完成、建议已过时或本手已换过牌时不会执行；建议保留全部时不改动历史。

升级时保留已有自定义按键。如果旧设置已占用 F7，新换牌快捷键暂不启用，请在设置中选择其他按键。

## 这一版改进

- 增加可自定义的扑克换牌快捷键（默认 F7），保留原来的识牌、归档、采用和重置快捷键。
- 修复草稿编辑期间旧建议继续显示的问题，并校验换牌建议对应的手牌顺序、历史和加成。
- 识牌忙碌期间阻止手牌与历史修改，避免异步截图覆盖撤销。

- 改进牌角二次读取：从纸面内部估计阈值，清理混入的桌面边条，保留浅色数字笔画。补充游戏字体的真实开口“4”与合成变体，保留原模型主读取，由两个补强模型复核读不清的点数。
- 增加整张牌的正反面/背景分类模型，先排除桌面文字、漂浮总点数和非牌面，再读取牌角。
- 更大的点数/花色网络与独立旧模型复核，结合两种牌角裁块、大小花色和红黑颜色检查；保留原有主读取模型，另加两个点数恢复模型，共 2,750,902 参数。
- 完整牌面定位、多尺度轮廓、四朝向校正；旧牌区不再强制裁切图片。
- 二十一点区分玩家牌、庄家明牌和不可读的背面；扑克区分当前五张与后方弃牌。
- 可靠且完整时自动计算；缺牌、重复牌、低分和归属不清时保留修改入口。界面不将模型分数称作准确率。

## 验证与边界

新增的 9 个开口“4”合成布局（3 种花色、3 个角度）均读对并自动计算；这些是针对性开发测试，使用了补强数据的字形，不是独立准确率或用户照片实测。

选定开发案例中，5 个完整桌面牌面均正确，4 个满足自动计算条件，另 1 个因遮挡留待核对；17 个无牌场景没有触发自动计算。按用户照片所示 9♣、8♣ 对庄家 A♥ 制作的 3 个合成布局均读对并自动计算。**合成布局不是用户原始照片；没有取得这 5 张原照片的本地像素文件，不能声称已对它们完成实测。**样本较少且有训练重叠，这些结果不是整体准确率，详见 tests/VALIDATION.md。

Windows CI 已用真实 WebView2、原生 EnumWindows 和 MSS 完成自建窗口截图与 RPC 验证。它没有运行真实游戏；游戏焦点、所有 DPI、多显示器和全局快捷键仍需实际游戏环境验证。不能承诺完美识别，遮挡、强反光、动画、特殊角度仍可能需要修正。

识牌与策略是两层功能。决策引擎沿用网页 v7.7.2，规则依据以原有 v1.0.30 资料为准；照片中的游戏 v1.0.33 未因此被声称完成全部规则复核。建议仅使用已经可见的牌，不会推断未知底牌。

## 源码开发

源码包先运行 `Setup-Windows.bat` 配置，再用 `Start-Windows.bat` 启动；支持标准 CPython 3.11–3.15 x64 环境；普通用户优先下载免装 Python 版。自由线程 Python 和 32 位环境暂不支持。Linux 各版本推理、JSON 返回值和中文模型路径验证见 tests/python-compatibility.json。开发者重新训练需另备视频帧及训练依赖；源码包不分发原始游戏视频。

`界面预览-无需安装.html` 只演示手动录牌与计算，桌面截图和模型推理由 app.py 提供。
