# 🎮 朋友，梭哈吧 · 游戏内策略决策器

**适用于 Steam《朋友，梭哈吧》的免费、离线、手机友好的策略辅助网页。**

> **用途声明：** 本工具仅用于分析不可兑换现金的游戏内虚拟游戏币、随机概率与道具收益；不涉及真钱赌博或真实博彩平台。与 Steam 或游戏开发者无官方关联。

**当前版本：v5.6** · **制作署名：旅人使用 GPT-6 制作**

## 🚀 立即使用

- **在线使用**：仓库开启 GitHub Pages 后，访问对应的 Pages 网址（见下方部署说明）。
- **离线使用**：下载 [GWYF_策略决策器.html](./GWYF_策略决策器.html)，用手机或电脑浏览器打开即可，不需要安装和服务器。
- **首次打开**：选择游戏；按牌面、进度、下注区域或持有道具输入情况；页面会即时更新概率、建议和期望收益。

| 模块 | 主要功能 |
| --- | --- |
| 🏆 游戏推荐 | 根据楼层、道具和规则模型排列玩法，并给出操作建议 |
| 🎯 轮盘 | 0–36、外围等投注区域的组合下注；命中概率、净盈利概率、各结果盈亏和期望收益 |
| 🎴 游戏百家乐 | 庄 / 闲 / 和的下注分析，按游戏版本规则计算 |
| ♠ 单人扑克 | 五张牌点数与花色输入、保留换牌建议 |
| 🃏 二十一点 | 硬手、A 软手、庄家明牌及要牌 / 停牌 / 加倍基础策略；本游戏无分牌 |
| 🎲 街头骰子 | 规则与下注结果的概率分析 |
| 🌈 颜色转盘 | 按颜色比较命中率、倍率与最终期望收益率 |
| 🎡 倍率转盘 | 各倍率结果、出现概率与最终期望收益率 |
| ⚖ 猜大小 / 🚀 Crash | 不同选择下的收益与风险估算 |
| 🐉 爬龙塔 / 🐧 企鹅跳冰块 / 💣 扫雷 | 当前进度、下一步风险与收益、从当前到目标阶段的连续成功概率 |
| 🏢 楼层图鉴 / 🎒 道具排行 | 游戏分布、道具选择与跨页面联动 |

**道具全局同步：** 一处选择或取消道具后，相关页面的收益模型与推荐会同步调整。神圣雕像在选中时按结算免亏处理，使用完可手动取消选中。

## 📱 手机使用说明

1. 下载单文件 HTML，或用 GitHub Pages 网址打开。
2. 在上方导航选游戏；手机可以左右滑动切换标签。
3. 按页面输入当前局面，查看建议和最终期望收益率。
4. 在游戏内拿到新道具或消耗道具后，更新道具选择即可。

轮盘和百家乐的**模拟下注**只是在网页里计算组合收益，并不会进行游戏内操作；网页不连接 Steam 账号、游戏服务器或真实博彩平台。

## 📊 如何理解数据

- **命中概率**：选择的下注区域在随机结果中命中的机会。
- **净盈利概率**：所有下注及道具效果结算后，本轮**净赚大于零**的机会；它与命中概率不同。
- **最终期望收益率**：基于当前模型，长期平均净收益相对于投入的比例；不是对单局结果的保证。
- **连续成功概率**：从起点或从当前进度持续成功到指定阶段的概率；具体以表格列名为准。

游戏内容和赔率可能随版本调整。部分玩法用公开攻略、玩家推导或概率假设建模；涉及物理操作、动态牌堆等情况时，结果可能与实际游玩有差异。**这里提供的是游戏内概率分析，而非必胜承诺。**

## 🌐 在 GitHub Pages 发布

1. 将本项目文件放入仓库的默认分支（通常 `main`）根目录。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 下选择 **Deploy from a branch**，选默认分支与 `/ (root)`，保存。
4. 等待 GitHub 完成发布，再访问 `https://<你的用户名>.github.io/<仓库名>/`。

根目录的 `index.html` 是完整网页，与可下载的 `GWYF_策略决策器.html` **字节完全相同**。发布 GitHub Pages 不需要额外构建步骤。
