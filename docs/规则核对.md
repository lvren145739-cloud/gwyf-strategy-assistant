# 《朋友，梭哈吧》规则与改进依据

核对日期：2026-10-18。原版：用户提供的 v5.6 HTML。资料基准为原版使用的游戏 v1.0.30；不能把社区整理称为已独立检查过游戏源码。本工具分析游戏内虚拟币。

## 保留的使用约定

- **直接选择道具生效数量，0表示不生效**。每种道具均可输入多个；这是用户明确要求的快捷逻辑，不拆成“拥有”和“激活”两个步骤。已知升级自动按层数计算，临时效果以实际合计强度和各自生效机制处理。
- 轮盘按整桌净额先合并，再计算利润与损失加成。原版记录：红黑各100，自信与保险开启时，非0仅返还200。该实测优先保留。
- 同一合并方式用于百家乐时标为工作模型，不能声称已在游戏中验证。
- 联机共享资金；相机是额外入账，应显示金额来源和“成功记录一次、第一格立即兑现”的假设，并提供独立的充能计算。

## 道具结算

- 自信：正利润倍率1+0.5×层数。
- 保险：恢复比例1−0.75^层数；两层是43.75%，不是50%。
- 利益相关者：受支持道具效果系数1+0.5×层数；不直接提高自信或保险，不影响配额枪/时光机。
- 饮料Tipsy与麦克风Melody、自信对正利润相乘；Melody的利润因子为1+Melody，且与保险恢复相加后封顶100%。选中麦克风沿用原版满充能默认，可在高级设置填写实际充能。
- 一杯饮料在Stakeholder=1时默认利润2倍。其余强度若未得到完整映射，允许输入实测Tipsy倍数，不凭空使用通用Stakeholder乘法。
- 雕像选中即按有效保护、亏损归零；不假定它会持续覆盖之后所有实际局数。
- 相机记录他人正利润，按Stakeholder入库；充能1/2/3/4格兑现倍率0.25/0.5/1/2。观察到亏局会清空库存，摔碎才兑现。
- 黄金筹码免除一次开局下注扣款，名义下注=当前桌面Max Bet×Stakeholder；免费本金和普通赌桌收益应分别展示。多区组合不擅自假设每一笔都能免费。
- 电击枪改最大下注，不改胜率；配额枪受剩余配额封顶；时光机会回滚近期结果；天使/恶魔转轮不等于必定恢复或增加收益。缺少确切分布的道具只给使用说明。

## 老虎机结构核对

[Justin Becker的逆向分析（2026-05-30）](https://justinbecker.dev/blog/2026/05/30/gamble-with-your-friends-casino-analysis/#slots)给出3×3盘面：八条横/竖/斜连线每项2×，菱形四格5×，X形五格20×，九格满盘59×；命中结构相加。其符号系数为Lotus 1.75、Beetle 1.25、Staff 0.75、Eye 0.25，网页中文仅作辅助译名，图标自绘示意。

同一符号满盘命中全部11项，结构基数 `8×2+5+20+59=100`，故四种符号满盘分别为175、125、75、25倍基础总返还。59倍只是满盘结构这一项。

四符号独立且每格等概率的假设下，占k格的任意同符号概率为 `4^(1−k)`，指定符号为 `4^(−k)`。八条连线互相重叠，不能相加当作整轮命中率。完整枚举4^9个盘面后，该模型毛返还约115.7150%，有返还概率约41.8182%，净盈利概率约32.4661%。

[当前社区Slots页](https://gwyfguides.com/games/slots)列出同数量及倍率的结构，记录千万种子重放毛返还1.155564725；并未独立核实名字符号映射和实时单符号概率。网页因此保留早期来源与模型标签，不把不同数据混成当前实局RTP。

## v7.5 二十一点动作求解

重新核对[社区Blackjack页](https://gwyfguides.com/games/blackjack)与上列逆向文章：单副持久牌堆、空堆重建、S17、初始两张加倍且只补一张、自然21立即3倍。原版不预查庄家自然21，因此求解器没有普通赌场“已排除庄家自然21”的条件。普通结算按点数比较。

[SplitWithFriends公开源码](https://thunderstore.io/c/gamble-with-your-friends/p/SimplyAG/SplitWithFriends/source/)展示对原版 `CalculateHandPayout(hand, dealerValue, handBet, allowBJ)` 的反射调用，提供普通牌按庄家点数结算的辅助证据；未将mod本身的分牌规则加入原版，也未独立验证当前原版程序集。

算法在抽牌后对玩家可见信息求最大期望，不先看到底牌再选择；已知完整手牌按剩余点数计数递归，快捷初始硬手枚举可行组成并按组合数加权。后期快捷点数无法知道组成，明确为近似。未知池只剩底牌时，底牌点数可推知，但仍保留在庄家手中，后续抽牌改从新52张牌池开始。

只对本游戏采用自信正利润加成、保险/雕像亏损减免、现有相机团队收益模型。社区该游戏页明确未将酒/麦克风列为直接互动，因此没有照搬全局其他赌桌的这两项加成。相机及公开规则口径仍有工作模型边界，结果不标称为独立验证过的实局最优策略。
