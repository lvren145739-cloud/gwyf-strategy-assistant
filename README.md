工具用于不可兑换现金的游戏内虚拟币、概率和道具收益分析，与Steam或游戏开发者无官方关联。

## 本次主要改进

- 手机直接选择分类下的游戏，总览随页面滚走；关键选择与推荐尽量同屏，轮盘保留完整横向桌面，无需左右滑动。
- 道具按当前生效数量录入，同种可以多个，相关页面同步更新。规则按公开原版配置固定，不再要求玩家选择H17或任意改赔率。
- **单人扑克**直接点具体牌，自动进入下一空位；完整比较32种保留方案。换掉的旧牌立即入历史，也可一键按推荐换牌；归档最终手牌时合并去重，避免漏掉弃牌。
- **二十一点**按当前手牌、明牌和已用牌比较要牌/停牌/加倍；历史点一次加一。逐张模式可录入庄家揭开的底牌和后续牌，一键归档双方全部已知牌。
- **老虎机**提供符号倍率、图案概率、九格实际盘面验算与注明假设的完整分布。
- 完善扫雷目标路线、继续/提现比较、弹珠样本记录、相机/免费筹码、资金记录、存档导入导出及资料说明。

## 边玩边用

1. 进入对应游戏，输入实际局面；道具数量表示**当前生效数量**，0表示不生效。
2. 扑克首次录入可点“重录五张”，依次点五张具体牌。计算后可按推荐换牌，也可点击对应手牌替换；旧牌立即排除。输错用“撤销录牌”，它会同时恢复手牌和历史。“重录五张”只更正输入，不自动当作游戏弃牌。
3. 二十一点逐张输入自己的牌和庄家明牌，查看同屏建议。庄家开始行动后，补录揭开的底牌及之后抽到的牌；本手结束点“归档双方牌 · 下一局”。未揭开的牌留空，不猜记。
4. 收起已用牌编辑区仍然应用历史。游戏实际洗牌/重建后，再清空对应历史。
5. v7存档可在右上角导出/导入。首次打开尝试迁移同一浏览器旧缓存；离线文件、不同网址或不同设备不保证共享存储。

## 如何理解建议

推荐以当前输入和页面注明的规则/结算模型为基础。命中率、净盈利概率和净期望含义不同；期望更高不保证这一局获胜。

二十一点逐张输入可准确扣除当前手牌；快捷初始硬手按可行组成加权，后期快捷点数组成不全时明确标为近似。未知底牌不提前揭示给求解器；庄家牌已经揭开时进入记录阶段，不继续给出基于未知底牌的建议。

规则主要按v1.0.30社区资料和公开逆向分析核对，未独立验证当前游戏程序全部分支。本手跨越实际重建边界、物理玩法和部分道具互动等限制见[更新日志的已知边界](./CHANGELOG.md#已知边界)及页面来源。工具不连接游戏或读取游戏种子。

## 源码与验证

发布文件内含全部样式、数据和算法，无第三方前端资源。源码在 `src/`，构建不依赖前端打包器：

```sh
python scripts/build.py --check
node scripts/verify.mjs
node tests/engine.test.js
node tests/blackjack.test.js
```

修改源码后运行 `python scripts/build.py` 生成两个入口文件。修改字节后须重新生成发布校验文件；旧签名不会自动继续有效。

浏览器回归脚本在 `tests/browser_v77*.py`，需要Python Playwright及Chromium；报告包括全部22页和本次新增换牌/归档流程。开发中数值检查共3,892项，覆盖完整百家乐发牌、扑克牌型/保留求解和隐藏底牌参考枚举；具体见报告。

GitHub Pages沿用 `main` 分支根目录发布，访问网站无需另做构建。v5.6原文件和原校验资料保留在 `archive/v5.6/`。
